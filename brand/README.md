# Metron brand assets

The only canonical Metron mark and wordmark are [`images/m-cropped.png`](../images/m-cropped.png) and [`images/metron-cropped.png`](../images/metron-cropped.png), respectively; use those source files for every new export and do not revive or derive assets from the retired January 2026 Sharp M + Space Grotesk kit archived under [`.graveyard/2026-11/`](../.graveyard/2026-11/). After changing an export, run `python3 scripts/verify-brand-assets.py` from the repository root to verify the required PNG and ICO sizes, active-page references, and local links.
